## Disegno

Trasforma una foto in un disegno e lo disegna da solo col mouse, in qualsiasi app
(Paint, Photoshop, Krita, siti web, Roblox…).

### File

- **Disegno-…-setup.msi**: installer (menu Start + Desktop).
- **Disegno.exe**: versione portatile, basta aprirla.

Windows 10/11 a 64 bit. Se compare «Windows ha protetto il PC», clicca
*Ulteriori informazioni → Esegui comunque* (il programma non è firmato digitalmente).

### Come si usa

1. Apri o incolla una foto (resta nella libreria).
2. Scegli stile, dettaglio e ombre guardando l'anteprima.
3. «Seleziona area»: 5 secondi per l'angolo in alto a sinistra, 5 per quello in basso a destra.
4. «DISEGNA» e non toccare il mouse. **ESC** ferma, **F8** mette in pausa.
